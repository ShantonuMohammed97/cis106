## What is a graphical user interface (GUI)?
A graphical user interface (GUI) is a visual system that lets users interact with computers, smartphones, and other electronic devices using graphics like icons, buttons, windows, and menus instead of typing text commands.

## What is a desktop environment?
A desktop environment (DE) is a collection of software running on top of an operating system that provides the graphical user interface (GUI). It determines how your digital workspace looks, feels, and behaves, allowing you to interact with your computer using visual elements instead of typing text commands.

## What is the command line interface (CLI)?
A Command Line Interface (CLI) is a text-based tool used to interact with a computer's operating system or software by typing lines of text commands rather than clicking on visual icons or menus.

## How do I access the command line interface (CLI)?
How you access the Command Line Interface (CLI) depends entirely on your operating system.

## What is a virtual console?
A virtual console is a software emulator or specialized interface that lets a modern device run classic video games or operate a simplified text-based computer system.

## What is a terminal emulator?
A terminal emulator is a software program that allows you to interact with your computer's operating system using text-based commands. It essentially mimics the functionality of old-fashioned, physical hardware terminals (like the VT100) inside a modern graphical user interface (GUI) window.

## What is bash?
Bash (Bourne Again SHell) is a command-line shell and scripting language used to interact with Unix-like operating systems, such as Linux and macOS.

## What is the shell prompt?
A shell prompt is a short sequence of characters displayed in a command-line interface (CLI) to show that the system is ready to accept user input


## clear
* **Definition:**
  * Clears the terminal screen.
* **Usage:**
  * `clear`
* **Example:**
  * To clear the screen, type `clear` and press Enter

## echo
* **Definition:**
  * Displays text on the screen.
* **Usage:**
  * `echo` + `option` + `string to display`
* **Example:**
  * How to display a line of text:
  * `echo "Hello"`
  * How to display two lines of text:
  * `echo -e "First line\nSecond line"`

## date
* **Definition:**
  * Displays the current date and time.
* **Usage:**
  * `date` + `option`
* **Example:**
  * To show the current date and time,type `date`

## free
* **Definition:**
  * Shows how much memory (RAM) is used and available.
* **Usage:**
  * `free` + `option`
* **Example:**
  * How to display memory in an easy-to-read format,type `free -h`
## uname
* **Definition:**
  * Displays information about the operating system.
* **Usage:**
  * `uname` + `option`
* **Example:**
  * How to display detailed system information: type `uname -a`

## history
* **Definition:**
  * Displays commands you entered earlier.
* **Usage:**
  * `history` + `number`
* **Example:**
  * To display your command history: type `history`

## man
* **Definition:**
  * Opens the manual page for a command.
* **Usage:**
  * `man` + `command`
* **Example:**
  * To read the manual for the `date` command: type `man date`

## tldr
* **Definition:**
  * Shows short examples that explain how to use a command.
* **Usage:**
  * `tldr` + `command`
* **Example:**
  * To see examples for the `date` command: type `tldr date`

## cheat
* **Definition:**
  * Shows a cheat sheet with useful command examples.
* **Usage:**
  * `cheat` + `command`
* **Example:**
  * How to see a cheat sheet for the `tar` command:
  * `cheat tar`

## hostname
* **Definition:**
  * Displays the computer’s name on the network.
* **Usage:**
  * `hostname` + `option`
* **Example:**
  * To display the computer’s name: type `hostname`

## df
* **Definition:**
  * Shows used and available disk space.
* **Usage:**
  * `df` + `option`
* **Example:**
  * How to display disk space in an easy-to-read format:
  * `df -h`

## du
* **Definition:**
  * Shows how much disk space a file or folder uses.
* **Usage:**
  * `du` + `option` + `file or folder`
* **Example:**
  * How to display the total size of the Documents folder:
  * `du -sh Documents`

## figlet
* **Definition:**
  * Displays large decorative text in the terminal.
* **Usage:**
  * `figlet` + `text`
* **Example:**
  * How to display the word “Hello” in large letters:
  * `figlet Hello`
