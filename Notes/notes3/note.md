## What is a graphical user interface (GUI)?
A graphical user interface (GUI) is a visual system that lets users interact with computers, smartphones, and other electronic devices using graphics like icons, buttons, windows, and menus instead of typing text commands.

## What is a desktop environment?
A desktop environment (DE) is a collection of software running on top of an operating system that provides the graphical user interface (GUI). It determines how your digital workspace looks, feels, and behaves, allowing you to interact with your computer using visual elements instead of typing text commands.

## What is the command line interface (CLI)?
A Command Line Interface (CLI) is a text-based tool used to interact with a computer's operating system or software by typing lines of text commands rather than clicking on visual icons or menus.

## How do I access the command line interface (CLI)?
How you access the Command Line Interface (CLI) depends entirely on your operating system.

## What is a virtual console?
A virtual console is a software emulator or specialized interface that lets a modern device run classic video games or operate a simplified text-based computer system.

## What is a terminal emulator?
A terminal emulator is a software program that allows you to interact with your computer's operating system using text-based commands. It essentially mimics the functionality of old-fashioned, physical hardware terminals (like the VT100) inside a modern graphical user interface (GUI) window.

## What is bash?
Bash (Bourne Again SHell) is a command-line shell and scripting language used to interact with Unix-like operating systems, such as Linux and macOS.

## What is the shell prompt?
A shell prompt is a short sequence of characters displayed in a command-line interface (CLI) to show that the system is ready to accept user input
