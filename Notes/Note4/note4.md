## 1. How to install and remove software using the APT command. Include several well documented examples as you will need to install software later?
* Formula to install any software: `sudo + apt + install + package name`
* To search any software: `apt + search + "tetris"`
* To remove: `sudo + apt + remove + package name`
* To purge : `sudo + apt + purge + package name`
* To full upgrade : `sudo + apt + full-upgrade + package name`

## 2. How to create a shell script step by step including screenshots and how to run it?
* Step 1: Open the text editor application
* Step 2: Save the file name as `FileName.sh`
* Step 3: The first line in the file must be shebang or shell interpreter. In the case of bash it would be **#!bin/bash**
* Step 4: Save the update
* Step 5: To run the script, use the following command on terminal: `bash ~/folder name/file name`
